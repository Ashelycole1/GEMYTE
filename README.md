# Gemyte 💎 - Cyber-Academy

Gemyte is an AI-driven academic gamification platform built around the "Study-to-Play" loop. It orchestrates RAG knowledge injection into a responsive internal 3D scene built with React Three Fiber, allowing students to interact, study, and play in a seamless 3D node-based interface.

![Gemyte Banner UI](https://raw.githubusercontent.com/shadcn-ui/ui/main/apps/www/public/og.png)

## Overview

### Architecture Phases Completed:
1. **Pilot Ingestion UI (Phase 1):** Drag & drop interfaces via Framer Motion simulating deep RAG vector data ingestion terminals.
2. **AI Orchestration & RAG Parser (Phase 2):** Blueprint generation parsing physical documents into JSON-structured knowledge trees logically spawning across the Orbit Controls viewport dynamically computing density/difficulty.
3. **Interactive Knowledge Gates (Phase 3):** Raycasting hooks bind 3D elements to DOM `KnowledgeModal` overlays, utilizing `Zustand` state managers crossing standard Canvas barriers for scoring and validation logic.
4. **Social Engine & Persistence (Phase 4):** Persistent local score caching and Leaderboard generation alongside "Final Form" Gem evolving rendering states utilizing optimized three.js material lerping.

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repo_url>
   cd Gemyte
   ```

2. **Install Node.js & Dependencies:**
   - Powered by Node `v22+`
   ```bash
   npm install
   ```

3. **Start Development Engine:**
   ```bash
   npm run dev
   ```

4. **Production Export:**
   ```bash
   npm run build
   ```

## Design System

We employ a dark gradient theme utilizing:
- **Neon Cyan** (`#06b6d4`): For successful validations and interactions.
- **Deep Violet** (`#8b5cf6`): For baseline aesthetic gradients and system rankings.
- **Emergent Emerald** (`#34d399`): Representing ultimate knowledge achievement states.

*Powered by Vite, React Three Fiber, Framer Motion, and Tailwind CSS.*
