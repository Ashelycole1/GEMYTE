Introduction to Algorithms and System Constraints

A binary search has a time complexity of O(log n).
Hash maps resolve collisions using techniques like chaining and open addressing.
The CAP theorem states that a distributed data store cannot simultaneously provide more than two out of the following three guarantees: Consistency, Availability, and Partition tolerance.
In machine learning, backpropagation is a method used to calculate the gradient of the error function with respect to the neural network's weights.
In cryptography, symmetric encryption uses a single key to encrypt and decrypt, while asymmetric uses a public/private key pair.
